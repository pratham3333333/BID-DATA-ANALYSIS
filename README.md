## ✅ Q1. Define Big Data and Explain its Key Characteristics.


**Answer:**  
Big Data refers to extremely large and complex datasets that traditional data processing software cannot handle efficiently. It is characterized by the **5 Vs**:

1. **Volume** – Refers to the vast amount of data generated daily.  
   *Example: Facebook generates over 4 petabytes of data per day.*

2. **Velocity** – The speed at which data is generated, collected, and analyzed.  
   *Example: Stock market data is streamed in real time.*

3. **Variety** – Data comes in various forms: structured, semi-structured, and unstructured.  
   *Example: Emails, social media posts, videos, and databases.*

4. **Veracity** – Refers to the trustworthiness and accuracy of data.  
   *Example: Fake news on social media affects veracity.*

5. **Value** – The insights and benefits extracted from data.  
   *Example: Netflix uses Big Data to recommend content, increasing user engagement.*

## 🔹 Q1. Explain the Apriori Algorithm in detail with the help of an example.

### ✅ What is Apriori?
Apriori is a **data mining algorithm** used to find **frequent itemsets** in a large dataset and discover **association rules**.

### 🔄 How it works (Simple Steps):
1. Count item frequency (Support).
2. Filter items above minimum support.
3. Combine frequent items to find bigger patterns.
4. Create **if-then rules** (like: If A, then B).

### 📦 Example:
Suppose we have a mini supermarket with these transactions:

- T1: Milk, Bread  
- T2: Milk, Diaper  
- T3: Milk, Bread  
- T4: Bread, Diaper  
- T5: Milk, Bread  

We find:
- Milk = 4 times  
- Bread = 4 times  
- Milk + Bread = 3 times

✅ Rule: *If customer buys Milk, they also buy Bread*  
**Confidence**: 3 out of 4 (75%)

## 🔹 Q2. Discuss linear regression in detail.

### ✅ What is Linear Regression?
It’s a method to **predict a value (Y)** based on another value (X).  
It shows a straight-line relationship.

### 📘 Formula:
\[
Y = a + bX
\]  
- *Y*: What we want to predict  
- *X*: Known value  
- *a*: Starting point (intercept)  
- *b*: Slope (change rate)

### 🏠 Example:
Let’s predict house price based on size:

- X = Size in sq ft  
- Y = Price

If:  
\[
\text{Price} = 50000 + 200 \times \text{Area}
\]  
Then for 1000 sq ft:  
Price = ₹2,50,000

A flowchart-like tree used to **classify data** into categories (e.g., Yes/No).

- Sensitive to small changes
- Not good with continuous updates

## 🔹 Q5. Build a predictive model using ARIMA to forecast sales for e-commerce.

### ✅ What is ARIMA?
ARIMA = **AutoRegressive Integrated Moving Average**  
Used to predict future values based on past data.

### 🔍 Key Parts:
- AR (AutoRegression)
- I (Integrated - differencing to remove trends)
- MA (Moving Average)

### 🛒 Example:
An online store tracks monthly sales:
- Data shows steady growth
- Use ARIMA to predict next 3 months’ sales

Prediction:  
April: ₹50,000  
May: ₹52,000  
June: ₹54,500
